#### Course Grade Weight Calculator

A lightweight, interactive Python web application that allows students and educators to dynamically adjust course syllabus weights and calculate final grades in real-time. 

#### Features

* **Dynamic Assessment Setup:** Edit evaluation category names (e.g., Final Exam, Homework, Attendance) and adjust their percentage weights on the fly.
* **Safety Validations:** Automatically checks if the total weight distributions equal exactly 100% before allowing calculations, preventing mathematical errors.
* **Visual Progress Metrics:** Displays final calculated grades instantly with interactive colored UI metrics and a corresponding letter grade system (A–F).
* **Celebration Animations:** Triggers an animated balloon celebration when a final grade lands in the "A" range.

#### Tech Stack

* **Python** (Core logic and calculations)
* **Streamlit** (Interactive web UI framework)

#### How to Run This Project Locally

#### Prerequisites

Ensure you have Python 3.12+ installed on your machine. 

#### Installation

1. Clone this repository or download the source code files.
2. Open your terminal or PowerShell inside the project directory.
3. Install the required dependencies using the requirements.txt file: 

bash

pip install -r requirements.txt

Use code with caution.

#### Running the App

Launch the application by running the following command: 

bash

streamlit run app.py

Use code with caution.

The application will automatically open a new tab in your default web browser.
